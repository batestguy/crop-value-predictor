# Agent handoff template

Use this compact packet when work moves between the main agent and a
subagent. Do not copy unrelated conversation history or secrets.

```text
Role:
Objective:

Acceptance criteria:
-

Scope and relevant files:
-

Constraints and non-goals:
-

Known risks or unresolved questions:
-

Current evidence / gate state:
-

Implementation or review request:

Validation commands:
-

Expected handback:
- changed files, if any
- tests/checks and results
- remaining risks or blockers
```

Review handbacks must list findings first by severity (`critical`, `high`,
`medium`, `low`), with precise file and line references, impact, and a concrete
correction. A reviewer must remain read-only unless explicitly assigned to
implement a correction.
