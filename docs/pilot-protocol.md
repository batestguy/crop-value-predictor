# Calculator-only farmer pilot protocol

This protocol evaluates comprehension and usability of the approved,
farmer-entered calculator. It does not evaluate forecast accuracy or approve
automated prices, deployment, Stage 3, or Stage 4.

## Sample and consent

Recruit 10 farmers and 3 extension agents who use Android phones or a desktop
browser. Assign anonymous participant IDs, obtain verbal consent, and record
device class, browser, connection condition, and prior budgeting-tool use. Do
not collect names, phone numbers, farm locations, or entered figures.

## Moderated tasks

Ask each participant to set an area, select two crops, enter yield, selling
price, and all eight costs, compare the result, add an optional low/high range,
edit the second crop, print or save the report, reload, clear the draft, and
repeat the comparison after the first load with network disabled. Ask them to
explain hectares, tonnes/ha, NGN/kg, the ranking, and why the result is a
scenario rather than a promise or forecast.

## Observer rubric

Record each task as completed without correction, correction needed, or
blocked; record unit misunderstandings, whether edit/reset/offline states are
found, and a 1–5 helpfulness rating. The primary denominator is participants
who attempted each task. A critical blocker is a result from an incomplete
scenario, a unit or currency misunderstanding that changes the decision, lost
draft after reload, or a belief that the result is a forecast.

Proceed to follow-up only if at least 80% complete each core task without
correction and at least 70% rate the tool 4 or 5. Report blank results and
blocked attempts separately. Physical Android installation, recruitment, and
participant outcomes remain pending external work.
